# Poker Quiz

Онлайн-квиз с двумя ролями:

- ведущий создаёт вопросы, открывает подсказки, запускает раунды ставок и переводит игру на следующий вопрос;
- игроки отвечают числом, участвуют в ставках и выбывают при нулевом балансе.

## Что уже реализовано

- страницы `/host` и `/play`;
- банк вопросов с двумя подсказками на каждый вопрос;
- лобби игроков;
- фазы раунда: вопрос → ставки → подсказка 1 → ставки → подсказка 2 → ставки → вскрытие;
- банк, баланс игроков, пас, чек, колл, рейз;
- автоматический делёж банка между ближайшими ответами;
- single-instance файловое хранилище состояния в `.data/game-state.json`.

## Ограничения текущего MVP

- нет авторизации ведущего;
- нет side pots и all-in, поэтому игрок с недостатком фишек должен пасовать;
- хранилище рассчитано на один инстанс приложения.

## Локальный запуск

```bash
npm install

```

Приложение поднимется на [http://localhost:3000](http://localhost:3000).

## Продакшен-сборка

```bash
npm run lint
npm run build

```

## Куда деплоить

Для этой версии проще всего использовать `Railway`.

Почему:

- у приложения есть серверная логика и файловое состояние;
- `Vercel` неудобен для файловой персистентности;
- в `Railway` можно поднять один веб-сервис и прикрутить volume для данных.

## Деплой в Railway

1. Создай новый проект из GitHub-репозитория.
2. Добавь `Volume` и примонтируй его в `/data`.
3. Добавь переменную окружения `DATA_DIR=/data`.
4. Команда старта по умолчанию подходит: `npm start`.
5. После первого деплоя открой `/host`, добавь вопросы и запускай игру.

## Что логично сделать следующим шагом

- добавить код комнаты и настоящую многокомнатность;
- закрыть админку логином или секретной ссылкой;
- перевести хранение состояния на Postgres;
- добавить realtime через WebSocket вместо polling.
